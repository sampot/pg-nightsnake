# 燈籠蛇 (`pg-nightsnake`)

夜市打烊前把街上的燈籠一顆顆吞掉。蛇會自己一直往前走，你只負責轉彎——撞到圍籬、攤位或自己的身體就結束。

類型：**蛇** · 系列：街機

## 玩法

- **鍵盤：** 方向鍵或 `WASD` 轉彎，空白鍵暫停。**手機：** 點畫面右／下方的方向墊，或直接在盤面上滑。
- **不能回頭。** 只能左右轉，一百八十度掉頭會被忽略；手比蛇快的時候最多先記兩個轉彎。
- **紅燈籠**加一節、＋10 分（關卡越後面加分越多）。**金燈籠**每四顆出現一次，只掛 42 步，加兩節、＋50 分，熄掉會換回紅燈籠。
- **尾巴讓得出來。** 這一步正要空出來的尾巴格可以鑽進去，緊急時能救一命。
- **越吃越快。** 關卡內每吃一顆就快一點（有下限）；無盡模式從 200ms／格一路加速到 78ms／格。

**六關巡燈：** 15×15 的街，吃夠燈籠就過關，攤位一關比一關多——廟口直街（5 顆，空街）、兩排攤車（7）、十字燈廊（9）、四角戲棚（11）、巷弄迷宮（13）、燈海夜市（15）。過關重置蛇身並拿到關卡獎金，六關全過就通關。已解鎖的關卡下次可以直接選。

**無盡夜行：** 沒有目標，只有越來越快的節奏；每吃五顆就多冒兩個攤位（上限 44 個），拚本機最佳分數。新攤位不會擺在頭三格內，也不會把燈籠圍成死路。

**失敗：** 撞上圍籬、撞進攤位、咬到自己。

開局建議：先沿著外圈繞，把燈籠留在轉角前吃掉；蛇長之後別貼著自己的身體切內線，金燈籠時間快到就放掉。

## 遊玩

純 HTML／CSS／JavaScript，無 build 步驟。本機直接開 `index.html`，或經 Playgrounds／go 安裝。最佳分數、已解鎖關卡與靜音設定透過 `/api/kv/` 由宿主保存。

## 開發

```bash
npx vitest run
```

`game.js` 是無 DOM 的純邏輯：蛇身格子陣列、轉向緩衝、碰撞、燈籠生成（BFS 確認走得到）、計分與關卡推進，全是純函式，`turn`／`step` 都回傳新的 state，state 可以直接 JSON 存讀。`app.js` 只做 canvas 繪製、固定 tick 迴圈（`requestAnimationFrame` ＋ 內插）與輸入。規則調整請連同 `game.test.js` 一起改。
